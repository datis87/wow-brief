# Digest 2026-11-24-1816 UTC

## Class changes

[Druid] Proposed Druid Balance Talent Changes
Developers are considering merging the Starfire cast time reduction talent with the existing Wrath reduction talent in row one of the Balance tree. Additionally, the Moonfury damage buff may become baseline for Moonkin form and be replaced with a new talent.
So what: Expect these Balance tree talent adjustments to arrive in a future patch rather than a hotfix.
https://blizzardwatch.com/2026/11/24/official-wow-forever-podcast-episode-8-discusses-class-changes-pvp-and-economy/

[Hunter] Proposed Survival Hunter Talent Adjustments
To compensate for the undertuned Survival capstone talent Lacerating Strikes, developers plan to buff Mongoose Bite's damage percentage and allow its effects to stack instead of overwriting.
So what: Watch for raid performance data results which will determine when these Mongoose Bite changes go live.
https://blizzardwatch.com/2026/11/24/official-wow-forever-podcast-episode-8-discusses-class-changes-pvp-and-economy/

[Warlock] Planned Demonology Warlock Talent Consolidation
Developers plan to consolidate demon talents within the Demonology tree following community feedback.
So what: Look for Demonology talent updates in a future patch after dev design work is completed.
https://blizzardwatch.com/2026/11/24/official-wow-forever-podcast-episode-8-discusses-class-changes-pvp-and-economy/

[Warrior] Warrior Arms Gameplay Status Update
Developers confirmed Arms Warriors will not receive significant gameplay changes at this time to prevent power creep.
So what: Expect Arms Warrior talents and abilities to remain in their current state for now.
https://blizzardwatch.com/2026/11/24/official-wow-forever-podcast-episode-8-discusses-class-changes-pvp-and-economy/

[General] Caster Itemization and Faction Writ Bug Fixes Announced
Future updates will introduce more level 15-40 spell power gear to address item scarcity for casters, while a fix and reputation boost are planned for bugged Azeroth Commerce Authority and Durotar Supply and Logistics Writs.
So what: Watch for added leveling spell power gear and fixes to broken reputation Writs in upcoming updates.
